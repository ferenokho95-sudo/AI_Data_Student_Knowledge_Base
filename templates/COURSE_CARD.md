# Карточка курса

Заполняется командой конкретной программы перед передачей слушателям.

| Сведения | Значение |
|---|---|
| Название курса и группа | Заполнить |
| Учебная платформа | Заполнить ссылку |
| Расписание и часовой пояс | Заполнить |
| Вебинары | Заполнить ссылку и порядок входа |
| Записи и материалы | Заполнить место публикации |
| Сдача домашних работ | Заполнить способ сдачи |
| Сроки и порядок продления | Заполнить |
| Куратор и часы связи | Заполнить |
| Преподаватель и канал вопросов | Заполнить |
| Административные вопросы | Заполнить |
| Срок ответа на обращения | Заполнить согласованный срок |
| Порядок записи вебинаров | Заполнить правила программы |

Перед публикацией проверить все ссылки под учётной записью слушателя и убрать незаполненные поля либо явно указать, где уточнить информацию.
