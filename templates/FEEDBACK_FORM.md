# Обратная связь после занятия

Тема и дата занятия:

1. Насколько понятен материал по шкале 1–5?
2. Какой был темп: медленно / подходит / быстро?
3. Какой вопрос остался непонятным?
4. Были ли проблемы со входом, звуком, демонстрацией или материалами?
5. Нужна ли личная помощь куратора: да / нет?

Контакт для ответа — по желанию. Обезличенные ответы можно использовать для улучшения следующих занятий.
