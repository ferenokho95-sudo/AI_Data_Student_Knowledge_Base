# Как обновлять базу знаний

1. Найдите повторяющийся вопрос в журнале обращений.
2. Воспроизведите его на маленьком примере без персональных данных.
3. Обновите существующую статью либо создайте новую, если тема отдельная.
4. Напишите цель, условия, шаги, ожидаемый результат и маршрут помощи.
5. Добавьте статью в оглавление и запустите `python scripts/check_docs.py`.
6. Для изменений кода выполните `python scripts/check_examples.py`; ноутбук отдельно перезапустите с чистым ядром.
7. Укажите изменение в CHANGELOG.md и запросите просмотр у другого участника команды через pull request.

Не публикуйте личные обращения слушателей целиком. Точные правила, ссылки и сроки программы должны подтверждаться её командой.
