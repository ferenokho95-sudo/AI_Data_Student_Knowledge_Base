# Запуск и работа в Jupyter Notebook

## Запуск

Перейдите в папку проекта, где находится `.venv`:

```powershell
.venv\Scripts\python.exe -m notebook
```

Откроется браузер с локальным интерфейсом Jupyter. Если браузер не открылся автоматически, найдите в терминале локальный адрес, начинающийся с `http://localhost:` или `http://127.0.0.1:`.

Ссылка может содержать token для входа. Не отправляйте её целиком в общий чат. Терминал оставьте открытым: в нём работает сервер Jupyter.

## Первый ноутбук

1. Создайте новый ноутбук с Python-ядром либо откройте готовый `.ipynb`.
2. В первой ячейке выполните:

```python
import sys
print(sys.executable)
print(2 + 2)
```

3. Нажмите Shift+Enter для выполнения.

Результат второй строки вычисления — `4`. Путь к Python должен относиться к нужному окружению.

## Типы ячеек

- Code — исполняемый Python-код.
- Markdown — пояснения, заголовки и выводы. Они оформляются после Shift+Enter.

Разделяйте код и объяснение результата. Комментарий «всё работает» не заменяет вывод: напишите, что именно рассчитали и что получили.

## Если ноутбук не видит pandas

В кодовой ячейке выполните:

```python
import sys
print(sys.executable)
```

Сверьте путь с `.venv`. Для установки в текущее ядро можно использовать отдельную ячейку `%pip install pandas==2.2.3`. После установки перезапустите ядро и выполните ноутбук с начала.

## Перед сдачей

1. Сохраните ноутбук.
2. Перезапустите ядро и запустите все ячейки сверху вниз. Названия пунктов меню Restart Kernel и Run All могут различаться между версиями.
3. Убедитесь, что нет ошибок, а результаты появились заново.
4. Сохраните файл ещё раз.

Эта проверка обнаруживает зависимость от переменных, оставшихся после старых запусков. Порядок исполнения должен соответствовать порядку ячеек в файле.

## Остановка

Закройте ноутбук и завершите сервер через Ctrl+C в терминале. При следующем занятии запускайте Jupyter той же командой из нужной папки.
