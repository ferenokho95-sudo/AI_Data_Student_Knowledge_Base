# Как отправить домашнюю работу

## Что подготовить

- Ноутбук `.ipynb` или скрипт `.py` в формате, указанном преподавателем.
- Короткий README: задача, данные, способ запуска и выводы.
- Файл зависимостей, если использованы дополнительные библиотеки.
- Нужные для воспроизведения небольшие данные либо разрешённую ссылку на источник.

Не загружайте `.venv`, кэш, пароли, токены и чужие персональные данные. Для закрытых учебных материалов следуйте правилам доступа вашего курса.

## Проверка до отправки

1. Выполните ноутбук с чистым ядром сверху вниз.
2. Замените абсолютные пути вида `C:\Users\...` на относительные пути внутри проекта.
3. Проверьте, что файлы имеют понятные названия, например `hw01_pandas.ipynb`.
4. Добавьте выводы и ссылку на использованные данные.
5. Убедитесь, что файлы сохранены после последнего запуска.

## Через браузер GitHub

Если преподаватель принимает работу через GitHub:

1. Создайте свой репозиторий или используйте выданный для курса.
2. Откройте Add file → Upload files.
3. Перенесите файлы задания и README в окно загрузки.
4. Укажите понятное описание изменения, например `Add homework 1`.
5. Подтвердите изменения. Если вы работаете в общем репозитории, используйте предложенную командой ветку и pull request.
6. Откройте загруженный ноутбук и проверьте, что GitHub показывает нужную версию.

Файл для браузерной загрузки должен быть не больше 25 MiB. Для крупных данных используйте согласованное хранилище и ссылку, а не добавляйте датасет в репозиторий без необходимости.

## Куда отправлять ссылку

В форму домашнего задания на учебной платформе либо в канал, указанный куратором. Сообщение в личном чате не считается сдачей автоматически: способ фиксации результата задаёт курс.

Вместе со ссылкой укажите номер задания и короткий комментарий. Для закрытого репозитория предоставьте проверяющему доступ способом, принятым на курсе. Пароль от своего аккаунта не передавайте.

## После проверки

Прочитайте все комментарии. Если непонятно, что исправить, процитируйте конкретный пункт и сформулируйте вопрос. После доработки отправьте обновлённую ссылку или подтвердите изменения по правилам курса.
