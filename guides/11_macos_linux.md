# Python и окружение в macOS и Linux

Проверьте установленный интерпретатор:

```bash
python3 --version
```

Используйте версию, согласованную с курсом. Для примеров базы подходят Python 3.11/3.12. Не удаляйте системный Python: некоторые компоненты ОС могут зависеть от него.

В папке распакованного проекта создайте окружение:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m notebook
```

Здесь активация окружения не требуется, потому что указан прямой путь к его Python. Если предпочитаете активацию, используйте `source .venv/bin/activate` и затем `python -m ...`.

На некоторых Linux-дистрибутивах компонент venv устанавливается отдельно. Если создание окружения завершается ошибкой, сохраните сообщение и уточните пакет для вашей ОС у куратора или в документации дистрибутива. Не выполняйте `sudo pip install` ради обхода проблемы.

Проверка:

```bash
.venv/bin/python -c "import sys, pandas; print(sys.executable); print(pandas.__version__)"
```

Путь должен указывать на `.venv/bin/python`. Дальнейшая работа с ноутбуками совпадает с [основной инструкцией Jupyter](02_jupyter.md).
