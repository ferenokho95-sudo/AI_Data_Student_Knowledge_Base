# Минимум Git для учебного проекта

Git сохраняет историю изменений локально. GitHub размещает репозиторий и помогает обмениваться изменениями. Для сдачи через браузер команды Git не обязательны.

## Первый репозиторий

Установите Git с [официального сайта](https://git-scm.com/downloads). В папке проекта выполните:

```bash
git init
git status
```

Создайте `.gitignore`:

```gitignore
.venv/
__pycache__/
.ipynb_checkpoints/
.env
```

Добавьте конкретные файлы задания и сохраните изменение:

```bash
git add README.md requirements.txt homework.ipynb
git commit -m "Add homework"
```

Если Git просит имя и email, задайте свои данные автора:

```bash
git config --global user.name "Ваше имя"
git config --global user.email "Ваш email"
```

Для публичной истории можно использовать адрес приватности, предоставленный GitHub в настройках email. Команды выше содержат заменяемые примеры, а не реальные контактные данные.

## Отправка в свой GitHub-репозиторий

Создайте пустой репозиторий GitHub и используйте его HTTPS-адрес:

```bash
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

USERNAME и REPOSITORY замените своими значениями. Авторизация зависит от установленного менеджера учётных данных. Не добавляйте токен в команду или URL. Если предложен вход через браузер, используйте его.

## Частые ситуации

| Сообщение | Действие |
|---|---|
| nothing to commit | Проверьте, сохранён ли файл и действительно ли есть изменения |
| remote origin already exists | Выполните `git remote -v` и проверьте адрес |
| rejected, non-fast-forward | В удалённой ветке есть изменения; не делайте force push без понимания причины |
| файл не появился на GitHub | Проверьте `git status`, последний commit и факт успешного push |

Если появилась ошибка слияния, сохраните копию своей работы и обратитесь к куратору с текстом сообщения. Не удаляйте файлы и историю наугад.
