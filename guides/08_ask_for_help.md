# Как сформулировать запрос на помощь

## Хорошее обращение

Укажите цель, шаг, ожидаемый результат, фактический результат и уже выполненные проверки. Добавьте код и полный текст ошибки текстом. Скриншот полезен для интерфейса, но не заменяет копируемый traceback.

Пример:

> Выполняю первое задание в Windows 11, Python 3.12. При чтении sales.csv получаю FileNotFoundError. Ожидала таблицу из шести строк. Проверила: Path.cwd() показывает папку проекта, а файл лежит в examples. Как правильно указать относительный путь?

В этом случае можно сразу проверить `Path('examples/sales.csv')`, если ядро запущено из корня проекта. Если ноутбук открыт в папке examples, используйте `Path('sales.csv')`.

## Маршрут обращения

| Вопрос | Кому адресовать | Что приложить |
|---|---|---|
| Доступ, расписание, запись | Куратору | Курс, группа, дата занятия, текст ошибки |
| Установка или запуск | Куратору для первичной диагностики, далее техническому наставнику | ОС, версия Python, команда, ошибка |
| Смысл задания или модели | Преподавателю/наставнику через канал курса | Номер задания, код, своё понимание |
| Проверка затянулась | Куратору | Дата сдачи, ссылка, текущий статус |
| Договор и оплата | Административному контакту курса | Краткая тема в личном канале |

## Что убрать из сообщения

Пароли, токены Jupyter, API-ключи, содержимое `.env`, документы и данные реальных клиентов. Если ошибка возникает только на закрытых данных, покажите структуру и небольшой искусственный пример с теми же типами.

## Действия куратора

1. Зафиксировать вопрос и его влияние: блокирует ли обучение или сдачу.
2. Уточнить недостающие сведения одним сообщением.
3. Назначить ответственного и согласовать срок ответа.
4. Передать вопрос преподавателю или техническому наставнику при необходимости.
5. Проверить решение со слушателем и закрыть обращение.
6. Если проблема повторяется, добавить обезличенное решение в базу знаний.

Статусы журнала: новое → уточнение → в работе → решено. Отметка «решено» ставится после проверки результата, а не после отправки инструкции.
