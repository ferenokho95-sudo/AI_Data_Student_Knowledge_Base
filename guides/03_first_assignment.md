# Первое задание по анализу данных

## Задача

По небольшому набору продаж рассчитать общую выручку и выручку по товарам. Данные синтетические, не содержат информации о реальных клиентах.

Файлы: [first_analysis.ipynb](../examples/first_analysis.ipynb) и [sales.csv](../examples/sales.csv). Откройте ноутбук в папке `examples` из интерфейса Jupyter.

## Структура данных

| Поле | Смысл |
|---|---|
| date | Дата продажи |
| product | Название товара |
| quantity | Количество единиц |
| unit_price | Цена одной единицы в рублях |

## Последовательность

1. Загрузите CSV через pandas.
2. Проверьте размер таблицы, типы столбцов и количество пропусков.
3. Рассчитайте `revenue = quantity * unit_price` для каждой строки.
4. Сгруппируйте данные по товару и сложите выручку.
5. Отсортируйте результат по убыванию и сформулируйте вывод.

```python
from pathlib import Path
import pandas as pd

data = pd.read_csv(Path('sales.csv'))
data['revenue'] = data['quantity'] * data['unit_price']
by_product = data.groupby('product', as_index=False)['revenue'].sum()
by_product = by_product.sort_values('revenue', ascending=False)
print(by_product)
```

## Контрольный результат

В исходном файле 6 строк. Общая выручка — 4 100 рублей. Наибольшая выручка у товара «Книга»: 2 000 рублей. Ноутбук содержит assert-проверки, подтверждающие эти значения.

Если контрольные значения не совпали, проверьте, что файл не изменён, выручка рассчитывается до группировки и используется цена одной единицы, а не сумма цен.
