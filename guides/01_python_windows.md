# Установка Python на Windows

## Что получится

В отдельной папке проекта будет окружение `.venv`. Пакеты курса установятся в него и не будут мешать другим проектам. Для материалов этой базы используйте Python 3.11 или 3.12; если преподаватель указал другую версию, следуйте требованиям курса.

## Установка

1. Откройте [официальный сайт Python](https://www.python.org/downloads/windows/).
2. Выберите установщик нужной версии для вашей архитектуры Windows. Для большинства компьютеров это x64.
3. В обычном установщике включите добавление Python в PATH и установку Python Launcher, если такие опции доступны. Интерфейс зависит от выбранного способа установки.
4. Завершите установку, закройте старые окна терминала и откройте новое.

Откройте PowerShell или командную строку и выполните:

```powershell
py --version
```

Ожидается строка `Python 3.x.x`. Если команда `py` отсутствует, проверьте `python --version`. Используйте найденный интерпретатор далее вместо `py -3`.

## Папка и окружение

Создайте через Проводник папку `C:\Projects\ai-course`. Перейдите в неё в терминале:

```powershell
cd C:\Projects\ai-course
py -3 -m venv .venv
.venv\Scripts\python.exe --version
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install pandas==2.2.3 notebook==7.3.2
```

Если установлены несколько версий Python, укажите нужную явно: `py -3.12 -m venv .venv`.

В инструкциях используется полный путь к Python окружения. Активация через PowerShell и изменение ExecutionPolicy для этого не нужны.

## Проверка

```powershell
.venv\Scripts\python.exe -c "import sys, pandas; print(sys.executable); print(pandas.__version__)"
```

Первая строка должна заканчиваться на `ai-course\.venv\Scripts\python.exe`, вторая — `2.2.3`.

## Если установка не прошла

- `py is not recognized`: проверьте установку Launcher либо используйте `python`.
- `No module named pip`: выполните `.venv\Scripts\python.exe -m ensurepip --upgrade`.
- Ошибка доступа к пакету: проверьте интернет и правила вашей рабочей сети. Сохраните полный текст ошибки для куратора.
- Команда запускает Microsoft Store: используйте `py`, если Launcher установлен, либо уточните путь к установленному Python.

Не переустанавливайте всё окружение при каждой ошибке. Сначала проверьте путь к интерпретатору и команду, на которой произошёл сбой.
