# Типичные ошибки и что проверить

Сначала сохраните полный текст ошибки и найдите последнюю строку traceback. Она обычно содержит тип ошибки и пояснение. Затем проверьте путь к Python и рабочую папку.

## Команды для диагностики

В ноутбуке:

```python
import sys
from pathlib import Path
print(sys.executable)
print(Path.cwd())
print([p.name for p in Path.cwd().iterdir()])
```

Перед отправкой вывода в чат уберите персональные части путей, если они не нужны для диагностики.

## Разбор

| Ошибка или симптом | Вероятная причина | Что сделать | Как проверить |
|---|---|---|---|
| `ModuleNotFoundError: pandas` | Пакет не установлен в выбранное ядро | Установить через `%pip install pandas==2.2.3` в этом ядре или через нужный Python | Выполнить `import pandas` |
| `FileNotFoundError` | Относительный путь считается от другой папки | Посмотреть `Path.cwd()` и расположение CSV | Проверить `Path('sales.csv').exists()` |
| `NameError` | Переменная не создана или пропущена ячейка | Выполнить предыдущие ячейки по порядку | Перезапустить ядро и Run All |
| `SyntaxError` | Ошибка записи выражения | Проверить кавычки, скобки и двоеточие | Повторно выполнить одну исправленную ячейку |
| `IndentationError` | Нарушены отступы | Использовать одинаковые отступы в блоке, обычно четыре пробела | Выполнить блок целиком |
| `KeyError` при выборе столбца | Название отличается от ожидаемого | Вывести `data.columns.tolist()` | Сверить регистр и пробелы |
| `UnicodeDecodeError` | Файл сохранён в другой кодировке | Уточнить кодировку источника; для старого CSV из Windows проверить `cp1251` | Прочитать файл и осмотреть русские названия |
| Все поля CSV оказались в одном столбце | Неверный разделитель | Посмотреть первую строку, при необходимости указать `sep=';'` | Проверить `data.shape` и названия колонок |
| `TypeError` при умножении | В числовом столбце строки | Посмотреть типы и некорректные значения, затем осознанно преобразовать | Проверить `data.dtypes` |
| Ячейка постоянно занята | Долгий расчёт или цикл | Прервать выполнение, проверить цикл на маленьком примере | Время работы стало ограниченным |
| Пакет установлен, но import не работает | pip относится к другому интерпретатору | Проверить `sys.executable`; использовать `python -m pip` из нужного окружения | Путь окружения совпадает с ожидаемым |
| Ноутбук работает только после ручных действий | Скрытая зависимость от старых переменных | Очистить состояние ядра и выполнить сверху вниз | Run All проходит без ошибок |

## Что не исправлять автоматически

- Не заменяйте все пропуски нулями, пока не понятен смысл пропуска.
- Не удаляйте строки только ради исчезновения ошибки: сначала выясните её причину.
- Не меняйте версии всех библиотек одновременно. Сохраните исходные версии и изменяйте одну причину за раз.
